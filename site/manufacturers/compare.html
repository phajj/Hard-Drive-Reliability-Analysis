Seagate vs Western Digital vs Toshiba

Seagate Western Digital Toshiba All three compared

2,000 random data drives from each maker, failed or not, all speeds together. We took the same number from each maker, not the same percentage, so Toshiba's smaller fleet gets as much weight as Seagate's. This is called stratified sampling with equal allocation. Each maker bought its drives in different years, so some of the gap between them comes from drive age.

Cumulative failures

Each dot is the total number of sampled drives in that manufacturer that had failed by the end of that quarter. Totals keep growing with how long each manufacturer has been observed, so compare them using the failure rates above.
