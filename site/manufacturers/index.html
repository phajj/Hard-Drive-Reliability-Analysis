Backblaze drive stats · failed HDDs from the 1000-drive failed sample, split by manufacturer. HGST and Hitachi count as Western Digital.

Each dot is one drive that failed. Across: the first day it shows up in the data. Up: how long it had been powered on when it failed. All charts use the same axes. Drives with suspect power-on hours are left out.

Drives first seen in April 2013 were already running when the data starts, so their first day is the start of the data, not the day they were installed. Newer drives haven't had time to run long, so the top right of each chart is empty by design.
